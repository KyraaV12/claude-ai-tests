Un point vert signifie que le navigateur a réellement exécuté la chose, pas qu'elle figure dans le fichier. Redimensionnez la fenêtre : la dernière ligne suit.

Contenu

Ce que contient la page

Un seul fichier, index.html, sans dépendance à installer : styles et script sont en ligne, les trois polices viennent de Google Fonts avec une pile de secours déclarée. La page suit le thème clair ou sombre de votre système, et le tracé de l'en-tête s'immobilise si vous avez demandé moins d'animations.

Rien d'autre n'est nécessaire pour l'ouvrir : un double-clic sur le fichier suffit.

Suite

Pour la servir

  • Localpython3 -m http.server 8000 à la racine du dépôt, puis localhost:8000.
  • En ligneActivez GitHub Pages sur la branche de votre choix : la racine contient déjà index.html.
  • EnsuiteDites-moi ce que la page doit faire, et je pars de cette base plutôt que d'une page blanche.
